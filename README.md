# Online Event Management System

## Project Overview

A full-stack web-based platform designed to simplify the process of organizing, managing, and attending events.

## Tech Stack

* **Frontend:** React.js, Vite, CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB (with Mongoose)

## Project Status

* **Phase 1 (Frontend):** Completed (UI components, Navbar, Dashboard, and Event management forms)
* **Phase 2 (Backend):** Completed (RESTful APIs, Server setup, and Controllers)
* **Phase 3 (Database):** Completed (MongoDB integration and Mongoose schemas)

## Features

* User Authentication & Authorization
* Event Creation and Management
* Event Browsing and Dashboard UI
